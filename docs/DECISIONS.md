# Conversa Architecture Decisions

This file records durable technical decisions.

## ADR-001: Feature-Based Git Branching

**Status:** Accepted

Branch names represent the work being implemented rather than project phase numbers. This keeps Git history readable and makes branches independently understandable.

## ADR-002: Repository Name

**Status:** Accepted

The application and repository are named **Conversa**. The previous working name "SignalChat" must not be used as the application name in new project artifacts.
