# Conversa Development Roadmap

The project plan is organized into implementation phases, but Git branches are **not** phase-based.

Phases are used to sequence delivery and track product progress. Individual implementation branches must use feature-oriented names such as:

- `feature/project-foundation`
- `feature/user-authentication`
- `feature/user-profiles`
- `feature/realtime-messaging`
- `feature/message-persistence`
- `feature/file-sharing`
- `feature/push-notifications`

The exact feature sequence follows the supplied project description and will be recorded as implementation progresses.
